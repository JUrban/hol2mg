## What changed since report 3

- Automatic definitions cover `new_specification` constants (defined as a chosen witness of the
  specification) and `new_type_definition` types whose type arguments occur only in the predicate
  (`(N)multivector`); definition arity follows the HOL right-hand side; the result role and
  Megalodon type follow the elaborated term's natural view; template results of meta role are
  sized by the mapping scheme; arity coercions in both directions (curried meta functions whose
  values are set-functions, via set application); reviewed **definition overrides** (`override`
  field: `vector_norm`, `distance`) keep the constant's name in statements while replacing the
  generated body.
- Elaboration fixes found by the Multivariate corpus: over-applied `COND`, partially applied
  connectives, bound function/boolean variables of lambdas as data, membership for
  predicate-valued data functions, sound eta (meta arities), keyword collisions (`at`),
  symbolic names (`-->` tendsto, `--->`, `++`, `$$`, `%`, `**`).
- Upstream-update workflow verified on an older HOL Light commit (`core_prev` profile in a git
  worktree): the manifest diff reports exactly one new theorem (`CARD_UNIONS_IMAGE`) between
  2026-05-18 and 2026-08-17; sequent hashes are now stable across sessions (invented type
  variables are canonicalised).
- `make test` self-test (build, determinism, golden, all core shards); HTML review pages.

## Critical look

1. Auto definitions are exact but not always idiomatic (e.g. `distance N (x,y)` keeps HOL's pair,
   `sqrt` of `norm` needed an override).  The override mechanism is the reviewer's lever; the
   review page lists every auto definition.
2. `A <> Empty` premises: ~2000 Multivariate statements are `generalization_required` (premise
   dropped by the syntactic evaluator); ~5000 keep a premise a reviewer might consider dropping.
   A Megalodon empty-case proof generator remains the principled next step.
3. The hand-written native modules (`prelude`, `finseq`, `order`) are the trusted base of every
   `transport_required` statement; 18 theorems there are still admitted (arithmetic bridges such
   as `minus_nat_omega`, `div_mod_nat`, `idx_n_equip`, and `seq_rev/filter/foldr` computation).
4. Full Multivariate update takes ~12 minutes (translation 1–2 min; 47 Megalodon shard checks,
   each re-reading the 2000-line definitions file).  Acceptable; could be parallelised.
