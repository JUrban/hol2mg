## What was done since report 9

1. **Dependent conjunctions and conditionals.**  While bridging the later conjunct of `a /\ b`,
   the native conjuncts of `a` are hypotheses in scope (`imp_and_dep`, `imp_and_dep_bwd`); the
   branches of `if c then x else y` are related under `c` / `~ c` (`hl_COND_if_dep`).  Side
   conditions of `CARD`, `sup`, `inf`, `HD`, `TL`, `LAST` inside such contexts are now discharged
   from the earlier conjuncts or the condition (`FINITE s /\ … /\ CARD s = CARD t`,
   `is_lub s l <-> ~ s = Empty /\ … /\ sup s = l`, `inf (SetAdjoin s x) = if s = Empty then …`).
2. **Bounds of real sets** are derived from hypotheses of the forms
   `forall x :e R, x :e s -> x <= b` (concrete bound), `abs_SNo x <= a`, `abs_SNo (x + - l) <= e`,
   `a <= x /\ x <= b`, with the bound terms real variables (`bound_*_concrete`, `bound_*_of_abs`,
   `bound_*_of_abs_shift`, `bound_*_of_pair`, `SNoLe_abs_SNo`, `minus_abs_SNoLe`).
3. **Lists.**  Conditional `HD`/`TL`/`LAST` (side condition `l <> seq_nil`, derived from
   hypotheses or structurally for `seq_cons h t`), `BUTLAST`, `ALL2` (`seq_all2` recursion over
   `nil`/`cons` with `seq_hd`/`seq_tl`), with the native sequence lemmas `seq_tl_cons`,
   `seq_last_cons`, `seq_butlast_nil/cons`, `seq_nth_cons_eq`, `seq_len_ordsucc_pred`.
4. **Lambdas into subsets viewed as binary predicates** (`\i. {x i}` as an argument of
   `cartesian_product`): related as `KPWP2` and coerced to a function into subsets
   (`rep_of_pw2`, `lam_subset_pw`); the derived/elaborated comparison is now alpha-insensitive.
5. **Compatibility theorems** (298 total; 270 at report 9).
