## What was done since report 12

1. **gcd / lcm / coprime.**  HOL Light's `int_gcd` is a *specification* (a function returning a
   nonnegative common divisor that is a linear combination — Bezout); to use it the native side
   must exhibit such a function.  `gcd_int_spec` shows that the prelude's `gcd_int` (a choice of a
   nonnegative `gcd_reln`) satisfies it, using God1's `least_pos_int_lin_comb_ex` and
   `least_pos_int_lin_comb_gcd`; conversely the specified value satisfies `gcd_reln` (any common
   divisor divides a linear combination and is bounded by a positive one), so `gcd_reln_uniq`
   identifies the two (`hl_int_gcd_compat`).  `coprime` is `gcd = 1` (`gcd_int_eq_1_iff`, both
   directions through Bezout), `lcm` uses exact division (`div_int_exact`: `div_int x y = x :/: y`
   when `y | x`, by the uniqueness of quotient and remainder), zero products
   (`mul_int_eq_0_iff`) and nonnegativity of the quotient; the `num_*` versions go through
   `num_of_int` on nonnegative integers.
2. **Compatibility theorems**: 385 total (367 at report 12).
