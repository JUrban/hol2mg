## What was done

1. **Compatibility theorems** (`mglib/literal/compat.mg`: 98 → 165 hand-proved theorems, all
   from the literal definitions; `carriers.mg` 25; bridge library `bridge.mg` 114; generated
   for Core: 453 typing, 213 unfolding, 23 specification lemmas):
   `DIV`/`MOD` (quotient–remainder uniqueness), `..` (numseg), `int_pow`, `real_sgn`,
   `int_sgn`, `int_max`/`int_min`, `PSUBSET`, `INFINITE`, `pairwise`, `int_divides`/
   `num_divides` (the God1 `divides_nat` uses `mul_nat`), `,` (pairs), `NIL`, `num_of_int`
   (choice with a unique witness), `real_zpow`, `dist`, `WF`, `CROSS` (two-variable
   comprehension over pairs), `==`, `neutral`/`monoidal` (choice extensionality
   `choose_in_ext`), `support`, `sum`/`nsum`, `sqrt` (the unique root with the sign of the
   argument), unique existence (`hl_exists_unique_lit`).
   The central lemma is `hl_itset_finsum`: the literal `ITSET` fold with an additive operation
   (HOL Light's choice of *any* function satisfying the recursion clauses) equals God1's
   `ring_finite_sum R add_SNo` on every finite set, by `finite_ind`, using
   `god1_ring_finite_sum_adjoin` (the real numbers are a ring by
   `god1_real_numbers_are_field`) and `god1_finite_sum_in_additively_closed_subset` (so the
   same fold serves `nsum` over `omega`).  `sum`/`nsum` compat then follows from the
   `iterate` unfolding, `hl_neutral R hl_real_add = 0`, and the support compat.
2. **Generator** (`lib/bridge.ml`, `lib/emptyproof.ml`, `lib/elab.ml`): lambda arguments in
   meta-function/meta-predicate positions (pointwise relation via `beta`; `sum s (\x. …)`),
   meta-predicates applied to rewritten arguments (Leibniz on the native side only),
   unique existence bridged through the elaborator's expansion, side conditions instantiated
   with the literal arguments (the `CARD` finiteness condition now discharges from a `FINITE s`
   premise), unique hypothesis names per implication, spine-based argument congruences in the
   empty-carrier prover (meta-level heads such as `finsum s f`), carrier parameters on
   instance compatibility statements (`hl_sym_3d3d int …`), template constants canonicalized.
3. **Defects found by certification** (the point of the exercise):
   - *Public statements*: `elab_binder` released a meta-function variable's name before
     generating its closure premise, so 14 Core statements on `dev/statements-v1` read
     `forall x:set -> set, (forall x :e omega, x x :e omega) -> …` (e.g. `NSUM_REFLECT`,
     `NSUM_SWAP`): the closure hypothesis was captured and vacuous.  Fixed; the golden file was
     reviewed and updated; these statements are now certified.
   - *Bridge proofs*: nested implication hypotheses shadowed each other (`H__hyp`), which a
     side-condition lookup by name could exploit (`CHOOSE_SUBSET`); the empty-carrier prover
     used the set-level congruence `f_equal2 (fun x y => x y)` on meta-level applications
     (ill-typed, caught by Megalodon); template constants (`hl_rep`) parsed as variables so
     side conditions never matched.  All caught by the `Qed` check, none by inspection.

## Techniques worth keeping (also in memory)

- `choose_in_unique` / `choose_in_ext` (`bridge.mg`) turn HOL's `@` into native definitions
  whenever the witness is unique or the predicates are equivalent on the carrier.
- Rewrites in goals containing `*`, `^`, `ring_finite_sum`, `finsum` hang Megalodon; every
  such proof is written as an explicit `eq_trans_i`/`f_equal` chain (generated from Python
  templates with `@TOKEN@` placeholders for the long ones).
- `finite_ind` and `nat_ind` are applied as `exact (… (fun X => P) Hbase Hstep …)` with the
  base and step stated beta-reduced.
