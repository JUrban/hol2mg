# Interim report 17 — native proof synthesis begins (2026-08-31)

Phase change (new goal): translate *proofs*, with the bar that the results read as good
native Megalodon proofs in the God1 / `examples/form100/100thms_12.mg` style — not as the
uniform-model implants of the §22 pilot (which remain the semantic safety net: 840 Core
theorems `fully_proved`, recorded and re-validated on every cycle).

## What exists after day one (DESIGN §23)

- **Design**: §23 — architecture (step mining at named-lemma granularity, native transport
  on the rigid fragment, declarative emission), the no-alien-implant quality bar, phases
  N1–N5.
- **N1 analytics** (`tools/native_proof_stats.py`): on the 1 725 recorded Core proofs the
  kernel-rule stream compresses only 2.2× naively; the named-lemma skeleton and rigidity
  analysis identify where native synthesis is worthwhile; 516 recorded proofs are fully
  rigid.
- **N2 prover** (`lib/nativeproof.ml`, ~300 lines): bounded declarative prover over the
  native statement AST; God1 idioms only (`let`/`assume`/`prove`/`apply`/`exact`/`witness`,
  bullets, `andI`/`iffI`/`orIL`/`orIR`, inline Leibniz equality, first-order instantiation
  of quantified hypotheses).  **302 of 2 685 public Core theorems now carry generated native
  proofs; the whole set Megalodon-checks in 3 seconds against God1 + native prelude +
  public definitions only, and the public shards emit them with `Qed` (`natively_proved`)** (`generated/nativeproof/core/`, `tools/check_nativeproof.sh`,
  regenerated by `tools/update.sh`).

## Sample generated proofs (as emitted)

```
Theorem num_divides : forall a b :e omega, divides_nat a b <-> divides_int a b.
let a. assume Ha.
let b. assume Hb.
apply iffI.
- assume H1.
  exact (divides_nat_divides_int (a) (b) H1).
- assume H.
  exact (divides_int_divides_nat (a) Ha (b) Hb H).
Qed.

Theorem COMPL_COMPL : forall A:set, forall s c= A, A :\: (A :\: s) = s.
let A.
let s. assume Hs.
apply (set_ext (A :\: (A :\: s)) (s)).
- let x1. assume Hx1.
  apply (xm (x1 :e s)).
  + assume H. exact H.
  + assume H1.
    claim L: False.
    { exact ((setminusE2 (A) (A :\: s) (x1) Hx1) (setminusI (A) (s) (x1) (setminusE1 (A) (A :\: s) (x1) Hx1) H1)). }
    exact (FalseE L (x1 :e s)).
- let x. assume Hx.
  exact (setminusI (A) (A :\: s) (x) (Hs (x) Hx) (fun hl__H : x :e A :\: s => ((setminusE2 (A) (s) (x) hl__H) Hx))).
Qed.
```

Both are indistinguishable in structure from the hand-written God1 proofs this project
maintains; every cited name (`set_ext`, `setminusE2`, `divides_nat_divides_int`, `xm`, ...)
is a God1 library fact.
